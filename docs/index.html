SIGNIBLE

A Sign Language Information Base and Linguistic Elements repository.

SIGNIBLE is a cross-linguistic resource for sign language data that is centered on the linguistic elements of sign languages. It serves to document, structure, and support comparison of linguistic elements across signed languages.

What the Repository Contains

Linguistic Elements and Segments

Linguistic elements refer to the categories used to describe sign language structure. These may include parameters such as handshape, movement, location, orientation, and non-manual features, as well as other structural elements. Adopting PHOIBLE's inventory-based approach to phonological segments, this repository adapts the model to the unique properties of sign languages. Within this model, segments are defined as the specific units within each linguistic element.

The current data centers on handshape segments, but additional elements will be considered in the future.

Notation Systems

Notation systems describe how linguistic elements are represented. There is no universally adopted notational standard for all sign languages. The repository uses the following notation systems:

  • Formal SignWriting in ASCII (FSW)
  • SignWriting symbols
  • HamNoSys

Additional forms of notation may be added in the future.

Inventories and Sources

Inventories list the identified segments of a linguistic element that pertain to a sign language entry in a dataset. The current inventories draw on more than one type of source. Current sources include:

  • Manually collected handshape inventories from 12 datasets compiled by Longqian Ming (2024).
  • Automatically extracted FSW data from 82 SignPuddle dictionaries.

Languages

Approximately 85–88 sign languages are currently assessed.

For SignPuddle inventories that identify a country but do not explicitly name a language, a Glottolog analysis was performed to attribute the language:

  • Where Glottolog lists only one sign language for a country, that language is assigned.
  • Where majority and minority or endangered languages coexist, the main national language is assigned.
  • Languages are combined if a country has more than one major sign language, such as Myanmar, Northern Ireland, and Vietnam.
  • Languages not listed in Glottolog remain included and are marked as such.
